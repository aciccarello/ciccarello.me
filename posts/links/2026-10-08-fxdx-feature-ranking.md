I love that the Firefox team is requesting feedback like this. It's a pretty nice way to give input on features you want to see in web dev. Here are some of the features I would like to see:

## Responsive iframes

 The <code>frame-&#8288;sizing</code> CSS property sizes an <code>&lt;iframe&gt;</code> to its content, avoiding scrolling within the iframe. ([Issue #1443](https://github.com/web-platform-tests/interop/issues/1443))

## Progressive rendering of JPEG XL and AVIF images

 Displays a preview version of the image while the rest downloads. ([Issue #1459](https://github.com/web-platform-tests/interop/issues/1459))

## JavaScript <code>Temporal</code>

 A modern and extensive date/time API to replace <code>Date</code>. ([Issue #1381](https://github.com/web-platform-tests/interop/issues/1381))

## Web app manifest <code>share_target</code>

 Allows an installed web app to appear in the device&#39;s share dialog as a target for shared content. ([Issue #1404](https://github.com/web-platform-tests/interop/issues/1404))

## CSS <code>flex-&#8288;wrap:&nbsp;balance</code>

 Distributes items in a multi-line flex container so each line has about the same number of items. ([Issue #1350](https://github.com/web-platform-tests/interop/issues/1350))

## CSS gap decorations

 <code>column-&#8288;rule</code> and <code>row-&#8288;rule</code> display decorative lines between columns and rows of a flex, grid, or multi-column layout. ([Issue #1374](https://github.com/web-platform-tests/interop/issues/1374))

## CSS <code>line-&#8288;clamp</code> property

 Limits the text in a block container to a certain number of lines. Also allows custom end text if content overflow occurs. ([Issue #1379](https://github.com/web-platform-tests/interop/issues/1379))

## CSS <code>random()</code> function

 Chooses a random numeric value within a specified range. ([Issue #1354](https://github.com/web-platform-tests/interop/issues/1354))

## CSS <code>if()</code> function

 An inline conditional value that returns a value based on a set of conditions. ([Issue #1343](https://github.com/web-platform-tests/interop/issues/1343))

## CSS <code>inherit()</code> function

 Like <code>var()</code>, but uses the parent element&#39;s value of the custom property. ([Issue #1453](https://github.com/web-platform-tests/interop/issues/1453))

## CSS <code>margin-&#8288;trim</code>

 Removes the margins of child elements when they meet the edges of the container. ([Issue #1444](https://github.com/web-platform-tests/interop/issues/1444))

## CSS grid lanes (masonry)

 <code>display:&nbsp;grid-&#8288;lanes</code> creates a layout where items are tightly packed into parallel lanes. ([Issue #1445](https://github.com/web-platform-tests/interop/issues/1445))

## CSS color gamut mapping

 Displays out-of-gamut colors (such as from <code>oklch()</code>) closer to the intended color, rather than clipping RGB channels. ([Issue #1394](https://github.com/web-platform-tests/interop/issues/1394))

## CSS <code>text-&#8288;size-&#8288;adjust</code> property

 Disables or modifies the browser&#39;s default text size adjustment on small screens. ([Issue #1353](https://github.com/web-platform-tests/interop/issues/1353))

## Contact Picker API

 <code>navigator.contacts</code> allows users to share selected entries from their contact list. ([Issue #1462](https://github.com/web-platform-tests/interop/issues/1462))

## CSS <code>corner-&#8288;shape</code> property

 Alternative shapes for <code>border-&#8288;radius</code>, such as squircles and bevels. ([Issue #1368](https://github.com/web-platform-tests/interop/issues/1368))

## Promises from programmatic scroll methods

 <code>scroll()</code>, <code>scrollTo()</code>, <code>scrollBy()</code>, and <code>scrollIntoView()</code> return promises that resolve when scrolling completes. ([Issue #1435](https://github.com/web-platform-tests/interop/issues/1435))
