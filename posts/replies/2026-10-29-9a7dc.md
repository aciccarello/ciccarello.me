I recalled seeing somewhere in a tc39 discussion that strict mode is not a pattern they want to repeat. I think it complicated browser engine code, was complex to bundle, and adoption was mixed. Not sure what convo that was but I did find [this meeting note](https://github.com/tc39/notes/blob/main/meetings%2F2017-07%2Fjul-25.md#L179).

I think CSS could implement something similar more simply with a special shorthand property. It'd be good to have some language level recommendations for code that doesn't need backwards compatibility. But that's also what a lot of CSS resets provide.
